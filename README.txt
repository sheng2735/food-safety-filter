冰箱食安互動濾鏡｜GitHub Pages 上線步驟
1. GitHub 建立 Public repository：food-safety-filter
2. 將 index.html、style.css、app.js 上傳到根目錄
3. Settings → Pages → Deploy from a branch
4. Branch 選 main，資料夾選 /(root)，Save
5. 等待產生 https://你的帳號.github.io/food-safety-filter/
6. 用 iPhone Safari 開啟，允許相機權限並測試。
注意：相機需 HTTPS。網頁會在手機本機合成照片，不會上傳照片。瀏覽器無法保證自動把圖片塞入 IG Story；可用「分享照片」，若 IG 未出現則先儲存再開 IG。
